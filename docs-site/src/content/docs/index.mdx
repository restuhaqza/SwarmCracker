SwarmCracker turns SwarmKit tasks into Firecracker microVMs: each workload gets
its own kernel and hardware isolation through KVM, without the operational
weight of Kubernetes.

```
swarmcracker CLI ──gRPC──▶ swarmd-firecracker (manager)
                                    │  SwarmKit orchestration
                                    ▼
                           swarmd-firecracker (worker)
                                    │
                    Executor ─▶ Firecracker microVM ─▶ KVM
                                    │
                          VXLAN overlay networking
```
